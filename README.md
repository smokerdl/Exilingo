# Exilingo

Exilingo — автоматический переводчик игрового чата Path of Exile.

Программа читает сообщения игрового чата из `LatestClient.txt`, переводит входящие сообщения в русский язык и позволяет переводить исходящие сообщения с русского на английский. Перевод выполняется через настроенную очередь провайдеров, поэтому для разных каналов можно использовать разные цепочки переводчиков.

## Первый запуск

После первого запуска Exilingo открывает окно настроек. Перед началом работы необходимо выполнить базовую настройку.

### 1. Указать путь к `LatestClient.txt`

В разделе **Общие** укажите путь к файлу лога Path of Exile:

`Path of Exile\logs\LatestClient.txt`

Например:

`C:\SteamLibrary\steamapps\common\Path of Exile\logs\LatestClient.txt`

После сохранения этой настройки Exilingo сможет отслеживать игровой чат и автоматически переводить **входящие сообщения**.

### 2. Откалибровать точку активации строки ввода игрового чата

Для перевода **исходящих сообщений** программе необходимо знать координаты точки, по которой нужно активировать поле ввода игрового чата Path of Exile.

В разделе **Общие** укажите координаты точки активации `X` и `Y`.

Точка должна находиться внутри строки ввода игрового чата. После правильной калибровки Exilingo сможет активировать игровую строку ввода, вставлять туда переведённое сообщение и отправлять его.

При отправке в канал `Local` программа использует локальный канал без специального префикса. Для остальных каналов используются стандартные префиксы Path of Exile (`#`, `%`, `@`, `$`, `&`).

### 3. Настроить переводчики

В разделе **Переводчики** можно включить нужные провайдеры и настроить их параметры.

Поддерживаются:

- **Google Translate** — используется без API-ключа и подходит как базовый переводчик.
- **Gemini** — требует настройки API-ключа и модели.
- **Groq** — требует API-ключа и настройки модели.
- **OpenRouter** — требует API-ключа и настройки модели.
- **Ollama** — работает через локальный сервер Ollama и не требует внешнего API-ключа.

Для облачных провайдеров, использующих API-ключ, ключ задаётся в соответствующем поле настроек. Секреты хранятся отдельно от обычного `config.json`.

### 4. Настроить Ollama

Если используется Ollama:

1. Установите Ollama.
2. Запустите локальный сервер Ollama.
3. Включите провайдер **Ollama** в настройках.
4. Укажите адрес Ollama, обычно:

   `http://127.0.0.1:11434`

5. Выберите модель из списка доступных моделей Ollama.

Список моделей формируется автоматически на основе установленных в Ollama моделей. Для получения списка Ollama должна быть запущена и доступна программе.

### 5. Настроить маршрутизацию

В разделе **Маршрутизация** для каждого канала задаётся **очередь провайдеров**.

Доступны каналы:

- Global
- Local
- Trade
- Party
- Guild
- Whisper

Провайдеры проверяются **в указанном порядке**. Если первый провайдер выключен или недоступен, Exilingo переходит к следующему провайдеру в очереди.

Например:

`OpenRouter → Gemini → Google`

означает, что сначала будет использован OpenRouter, затем Gemini, а Google Translate будет последним резервным вариантом.

Исходящие сообщения используют маршрут **Whisper**.

## Настройки Overlay

В разделе **Overlay** можно изменить:

- положение оверлея (`X`, `Y`);
- ширину;
- высоту;
- размер шрифта сообщений;
- канал отправки исходящих сообщений.

Изменения сохраняются в конфигурации и применяются при работе программы.

## Управление Overlay

- **Enter** — переключение режима взаимодействия с Overlay.
- **F5** — отправка текущего сообщения из поля ввода Overlay.

F5 предназначена именно для отправки сообщения и не переключает режим Overlay.

## Логи Exilingo

Лог работы программы хранится в файле:

`logs\exilingo.log`

Для исходного Python-проекта это каталог `logs` в корне проекта.

Лог содержит информацию о запуске программы, настройках, работе LogReader, маршрутизации, попытках перевода, выбранных провайдерах и ошибках.

API-ключи и другие секреты в снимке настроек, записываемом в лог, автоматически маскируются.

## Конфигурация

Основные настройки хранятся в `config.json`.

Секретные данные хранятся отдельно в `secrets.txt` и не должны публиковаться вместе с конфигурацией.

Не передавайте другим людям свой `config.json` или `secrets.txt`, если в них присутствуют персональные настройки или секретные данные.

## Важные замечания

- Path of Exile должен быть запущен, чтобы Exilingo мог отслеживать игровой чат.
- Путь к `LatestClient.txt` должен указывать на актуальный лог Path of Exile.
- Для исходящих сообщений особенно важна правильная калибровка точки ввода игрового чата.
- Облачные провайдеры зависят от доступности соответствующих API и могут иметь собственные ограничения и задержки.
- Ollama выполняет перевод локально, но требования к оперативной памяти и VRAM зависят от выбранной модели.
- Если основной провайдер недоступен, используйте очередь маршрутизации с резервными провайдерами.

## Тестовая версия

Текущая версия является тестовой сборкой. Перед использованием рекомендуется проверить работу выбранных провайдеров, входящих и исходящих сообщений, а также корректность маршрутизации для нужных каналов.
